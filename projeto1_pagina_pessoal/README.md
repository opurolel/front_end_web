# Projeto 1 - Página Pessoal
Projeto desenvolvido individualmente por Leonardo Delmondes

## Instruções para abrir
- Para abrir o projeto, dentro do repositório, vá em "code" e "download zip";
- Descompacte o zip e abra a pasta no VSCode;
- Entre na pasta "projeto1_pagina_pessoal";
- No arquivo "index.html" e com a extensão "Live Server" ativa, clique em "go live" no canto inferior direito e a página web será aberta.

## Páginas
  A primeira página apresenta uma apresentação, informações sobre mim, interesses, objetivos de estudo e contato.
  Já a segunda, que pode ser acessada na sessão de estudos, apresenta superficialmente meu projeto pessoal em desenvolvimento.

  O projeto possui:
  - Estrutura semântica;
  - Duas páginas html;
  - Links para navegação;
  - Quatro imagens: 2 referentes ao projeto pessoal, 1 minha e 1 personagem ilustrativo;
  - Listas ordenadas, não ordenadas e uma tabela;
  - Àudio contendo uma música do artista "Nujabes";
  - Formulário.

## Testes e uso de IA
  Todos os links de sessão e externos foram testados, além dos links de ida e volta entre páginas.
  A IA Claude foi utilizada para gerar a estilização em CSS.
